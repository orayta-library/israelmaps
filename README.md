# מפות ישראל - אפליקציה לווינדוס 11

אפליקציית מפות ישראל עם ממשק Fluent Design ותמיכה במצב אופליין.

## דרישות מקדימות

- Windows 11
- .NET 8.0 SDK
- Visual Studio 2022 (או JetBrains Rider)
- WebView2 Runtime

## התקנה

1. שכפל את הפרויקט:
```bash
git clone <repository-url>
cd IsraelMapsApp
```

2. בנה את הפרויקט:
```bash
dotnet restore
dotnet build
```

3. הרץ את האפליקציה:
```bash
dotnet run
```

## תכונות

- ✅ ממשק Fluent Design מודרני
- ✅ מפות OpenStreetMap חינמיות לחלוטין (ללא צורך ב-API Key!)
- ✅ חיפוש כתובות בעברית
- ✅ תמיכה במצב אופליין (cache אוטומטי של אריחי מפה)
- ✅ ממשק בעברית מלא (RTL)
- ✅ ללא עלויות - 100% חינמי

## שימוש במצב אופליין

המפות נשמרות אוטומטית ב-cache כשאתה גולש באזור ישראל. 
להפעלת מצב אופליין, לחץ על כפתור "מצב אופליין" בסרגל העליון.

## טכנולוגיות

- WinUI 3 (Windows App SDK)
- Leaflet.js - ספריית מפות קלה ועוצמתית
- OpenStreetMap - מפות חינמיות בקוד פתוח
- Nominatim - שירות geocoding חינמי

## הערות

- לשימוש מלא במצב אופליין, גלוש באזורים שברצונך לשמור לפני הכניסה למצב אופליין
- OpenStreetMap הוא פרויקט קוד פתוח ללא הגבלות שימוש
- חיפוש כתובות עובד דרך Nominatim (חינמי לחלוטין)
